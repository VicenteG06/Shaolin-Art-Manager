# INSTRUCCIONES DE INSTALACIÓN SHAOLIN ART MANAGER

## REQUISITOS
Para poder utilizar el programa **Shaolin Art Manager** es necesario contar con:
- Entorno de desarrollo integrado (IDE) *Apache NetBeans*, específicamente la versión 12.0
- JDK 8

## INSTRUCCIONES
### PASO 1 : Descomprimir el archivo .zip.

### PASO 2 : Abrir NetBeans.

### PASO 3 : En el menú superior, hay que seleccionar Archivo (File), luego Abrir proyecto (Open project).

### PASO 4 : En la ventana que aparece, buscar en donde se descomprimió el proyecto. 

### PASO 5 : Seleccionar la carpeta del proyecto, hacer clic en Abrir proyecto (Open project).

### PASO 6 : Seleccionar la opción *clean and build* y luego *run*.
